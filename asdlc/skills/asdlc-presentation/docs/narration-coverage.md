# Narration coverage and review

## Three complementary parts

| Part | Reader's question | Required content |
| --- | --- | --- |
| Introduction | Why does this slide matter? | Existing framing and argument, preserved during expansion. |
| Walkthrough | What does this visual actually say? | Meaningful labels, groups, steps, arrows, comparisons, and boundary conditions. |
| Details | How should I understand or apply it? | Concrete examples, distinctions, consequences, and qualifications. |

These are ordered segments, not three competing definitions or three unrelated summaries.
Do not force a third file when the walkthrough is sufficient; two files are a valid detailed slide.
Preserve the single-file format for existing or intentionally brief material.

## Coverage test

Inspect the actual visual, including text embedded inside an image.
List each meaningful group and relationship, then check where it is explained in the narration.
A listener should not need to read an unexplained diagram to recover the main argument.
Explain what arrows mean, not merely their color or direction.
Read important labels naturally; do not mechanically recite branding, decorative icons, or reference URLs.
Identify illustrative figures and examples rather than reporting them as implemented or measured facts.
Surface misleading simplifications or source conflicts; do not change a diagram's meaning silently.
More words are not the acceptance criterion. Ask a listener to explain the key distinctions.

## Build and video boundary

The detailed PPTX uses all selected segments; the original intro PPTX remains a separate output.
The compiled notes file is derived and may exceed 50 lines; edit the smaller source files, not the compilation.
Estimated speaking time is advisory, not a tested audio duration.
A narrated video needs enough time per slide; generating a PPTX does not generate or replace a video.
A tool that rewrites or summarizes narration creates another script requiring comparison with these sources.

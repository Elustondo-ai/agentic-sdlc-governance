Elustondo.ai ASDLC CLI: install once, initialize the current Git project.

positional arguments:
  {install,sprint,init,status,verify,next,baseline,dashboard,agent}

    dashboard           Serve the read-only local ASDLC dashboard
    agent               Inspect definitions; does not run an LLM

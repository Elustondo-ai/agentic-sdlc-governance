# Twelve-step lifecycle — current baseline

Source: the selected SDLC2 introduction, slide 01 visual, supported by its speaker notes and slides 10–12.
Order is preserved. Pablo requested the Stage 02 display name Purpose on 2026-10-19; earlier slides retain historical labels.
`00-governance` is additional governance, not a thirteenth lifecycle stage.
This file controls the lifecycle numbering used by this repository, its CLI and generated project stages.
R02 reports an older, different lifecycle in the external SDLC2 registry; that drift remains unresolved.
The external comparison was not re-evaluated in this correction; no stage reconciliation or renumbering is authorized.

The same areas recur in sprint and release cycles, guided by a product roadmap.
Step 09 contains the build/test iteration. Step 10 makes changes understandable and reviewable.
Step 11 checks the change in a real system: development/staging during a sprint, production at release scope.
High-level architecture precedes the POC. An unnecessary POC must not be fabricated to fill a folder.

The earlier October 8 foundational draft duplicated context and shifted stages; it is not controlling.
Its spreadsheet also mislabeled the later stages. Those artifacts were not imported as policy.

## Component decision to preserve

Every component has a canonical folder; not every folder is a component.
The standard component contains `docs/`, `types/`, `src/`, and `tests/`, with a README and optional scoped `AGENTS.md`.
High-level design identifies responsibilities and boundaries; low-level design specifies input/output types and contracts before implementation.
Parents document subcomponents and their locations. Components can contain code, Markdown, configuration, or other artifacts.
The presentation skill demonstrates this layout without claiming the reference application already follows it.

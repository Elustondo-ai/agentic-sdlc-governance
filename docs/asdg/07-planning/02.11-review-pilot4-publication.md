## Intended and actual changes

Version metadata and the runtime constant now identify `0.3.0-pilot.4`; root README links its ZIP, checksum and prerelease.
The original published pilot.3 manifest is preserved from its tag, rather than copied from the later local candidate.

The skill is excluded from the portable file list and client adapters; existing provider native discovery entries stay disabled.
Publication authorization does not grant client installation, lifecycle acceptance, deployment or hook trust.

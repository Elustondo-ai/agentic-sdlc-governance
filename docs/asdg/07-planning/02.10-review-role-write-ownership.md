## Enforcement and review decisions

[Control limits](../../../asdg/00-governance/docs/write-controls.md) distinguish deterministic path decisions from instructional compliance.
The CLI preflight computes ownership and checks ASDG-09 application targets against the existing sprint gate separately.
Trusted Codex hooks enforce those patch decisions only with externally supplied session-bound role context. Missing or mismatched context denies writes.
No native session-to-role bridge is installed: a trusted existing hook therefore blocks writes until a reviewed launcher supplies context. This compatibility consequence needs human review.
Claude has no installed ASDG hook; preflight invocation and compliance remain instructional. Native discovery, invocation, role retention and interception are unverified in both clients.
External/reserved-root OpenSpec stores need a separately reviewed runtime boundary; the checker never substitutes another store.
Path checks do not authenticate approvals or validate append-only receipt content, sprint meaning, or runtime behavior hidden inside documentation formats.
The existing sprint gate still rejects implementation paths containing `asdg`; ownership does not widen that permission.

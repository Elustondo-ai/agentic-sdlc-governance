# GitHub Copilot: skills align; named agents differ — Visual walkthrough

The left panel shows the common skill path and two instruction mechanisms. The root
AGENTS.md is increasingly shared across AI coding assistants. Copilot also supports a
repository-specific .github/copilot-instructions.md and path-focused instruction files.

On the right is an illustrative Copilot custom-agent profile under .github/agents. It
contains metadata and role instructions, but is not byte-for-byte interchangeable with Codex
TOML or Claude YAML. Native tool names and environment-specific fields must be checked
against the selected Copilot surface.

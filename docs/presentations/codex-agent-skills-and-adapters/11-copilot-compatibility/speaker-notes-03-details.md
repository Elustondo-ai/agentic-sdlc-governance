# GitHub Copilot: skills align; named agents differ — Deeper explanation

The Copilot ecosystem includes interactive IDE agent mode, CLI use, and GitHub cloud agents.
Their customization support is not identical; do not promise that every agent setting works
everywhere.

Our practical approach is to share the governing ASDG role and capability, then adapt only
the vendor-specific wrapper. We must verify discovery, selection, tool access, and real
output in each target environment.

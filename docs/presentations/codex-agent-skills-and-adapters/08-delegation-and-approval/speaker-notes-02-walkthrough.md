# Delegation is a workflow; approval is a boundary — Visual walkthrough

Follow the five stages. A human requests review of a particular candidate. The coordinator
delegates a precise task to an asdlc_reviewer subagent.

The reviewer receives context and may inspect files or run permitted checks. It returns
findings, evidence, and uncertainty. Only then does the human make the consequential
approval decision.

A reviewer's positive conclusion is evidence for the decision, but it does not itself grant
permission to stage changes, commit, push, or release.

# Named agent: a Codex TOML role, not a skill — Opening narration

A named agent is where we assign a specialized responsibility. Codex uses a TOML file for a
project-scoped custom agent, not a second AGENTS.md. The required fields are name,
description, and developer_instructions.

Optional settings control the model, reasoning effort, sandbox and specific tool
connections. Those details make the agent a specialized execution context.

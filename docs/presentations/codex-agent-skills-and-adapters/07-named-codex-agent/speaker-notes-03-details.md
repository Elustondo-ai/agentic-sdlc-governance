# Named agent: a Codex TOML role, not a skill — Deeper explanation

Do not confuse a Codex custom-agent name with the stable Agent IDs in our Personal Agent
System Registry. Registration and runtime configuration are separate concerns.

Nor should we assume that writing a TOML file starts a daemon, creates memory, or grants
authority. A parent session still needs to delegate a task, and final effects depend on
actual tool permissions and human approval.

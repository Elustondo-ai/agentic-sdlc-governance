# One methodology. Three execution environments. — Visual walkthrough

Read the three columns from left to right. The methodology defines engineering concepts and
review boundaries: stage, evidence, approval, and the requirements governing a change. A
skill packages a procedure that many actors may use, such as creating a component or
building a presentation.

A named agent specializes an actor: it has a job, operating instructions, tools, and a
delegated scope. These are related but not interchangeable. A file being found by an agent
runtime does not mean that its contents have been enforced.

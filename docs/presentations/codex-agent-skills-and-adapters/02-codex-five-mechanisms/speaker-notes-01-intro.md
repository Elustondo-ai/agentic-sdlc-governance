# Codex: five mechanisms, five readers — Opening narration

The phrase Codex domain-specific language is useful shorthand, but it hides several
different interpreters. Codex does not parse every Markdown file as an agent definition, and
a command-looking sentence is not an installed command.

These five mechanisms carry different responsibilities. We should name the reader of each
artifact whenever we introduce a rule.

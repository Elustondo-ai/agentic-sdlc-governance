# Compatibility is measured, not assumed — Opening narration

A platform-comparison table is an architectural hypothesis. It is valuable because it tells
us where to look and where adaptation is unavoidable.

It is not evidence that three agents will interpret a rule identically. The right test is
behavioral: given the same representative ASDLC task, do they find the right sources, stay
within scope, use the proper checks, and report honest outcomes?

# Why an adapter exists at all — Opening narration

Your question about the apparently duplicated presentation skill was important. We
deliberately want the real skill definition in a meaningful directory, under asdlc/skills.

But native discovery expects a particular location. We therefore need a thin compatibility
surface that allows the runtime to find the capability without making that surface its
authoritative implementation.

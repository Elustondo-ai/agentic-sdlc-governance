# Slide 05 — Visual walkthrough

There are three areas on this slide. On the left, Scattered Knowledge includes meeting notes, unwritten intent, an issue tracker, and old diagrams. The caption makes a distinction: someone who was there may reconstruct the context, while a newly arriving agent is missing part of it.

The middle box, Shared Project Context, lists five things to make available in the repository. Intent and success criteria explain the outcome and how to judge it. Use cases and the system model describe actors and behavior. Architecture and design describe the chosen structure. Policies and quality gates set constraints. Release and sprint status locate the current work in its cycle.

The three words beneath that list matter. Versioned means we can identify which state of the knowledge a decision used. Scoped means we select what is relevant rather than indiscriminately load everything. Reviewable means a person can inspect and correct it.

The arrow to the right leads to implementation, tests and evidence, and questions for humans. Questions are an intended output when the context is incomplete. The bottom line asks us to make relevant knowledge available where agents work. It does not promise that an agent will infer a missing fact merely because many documents exist.

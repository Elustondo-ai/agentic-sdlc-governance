# AA02 — A shared architectural language

The common layer defines the meaning of a task, the context it may use, the tools it may invoke, the evidence it must produce, and the policies that constrain it. Approval is a defined event with a particular subject and state, not just a reassuring word in a prompt.

The two lower branches specialize that language. In development, SDLC2 speaks about stages, artifacts and review. In LifeBuckets, an application agent might speak about buckets, actions and confirmation. Those product terms are illustrative, not a claim that this schema already exists.

This is the reuse we want: shared architectural concepts and traceable contracts, with platform-specific adapters. It is not the reuse of a single prompt file or a single agent implementation.

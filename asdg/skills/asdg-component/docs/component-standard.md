# ASDG component standard

A component owns a folder containing `README.md`, `docs/`, `types/`, `src/`, and `tests/`.

`docs/` has `00-governance/` and the twelve official ASDG stages, each containing a short README marked uncompleted until supported by evidence.

`types/` accepts Markdown, Python, TypeScript, schemas or other suitable notations; no mandatory type language.

The generator must not overwrite existing content. Scaffolding does not constitute approval, implementation, or lifecycle completion.

The component is owned by its project; reusable agent instructions are kept separately under `asdg/skills/`.

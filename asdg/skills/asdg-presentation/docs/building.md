# Build and verify

## Setup

Requires Python >= 3.9 and a working Cairo system library.
Install the pinned Python packages in an isolated environment from the repository root:
```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r asdg/skills/asdg-presentation/requirements.txt
```
This does not install the system Cairo library or system fonts; arrange those for your platform.

## Commands

```sh
python3 asdg/skills/asdg-presentation/src/build.py --all --check
python3 asdg/skills/asdg-presentation/src/build.py --all
python3 asdg/skills/asdg-presentation/src/build.py --presentation docs/presentations/asdg-introduction
python3 asdg/skills/asdg-presentation/src/build.py --presentation docs/presentations/asdg-introduction --narration detailed
python3 -m unittest discover -s asdg/skills/asdg-presentation/tests -v
```

## Output

Each deck receives `build/<presentation-name>.pptx`, `build/preview.png`, and `build/build-manifest.json`.
The `detailed` profile instead writes `<name>-detailed.pptx`, `preview-detailed.png`, and `build-manifest-detailed.json`.
Both profiles also write `<name>[-detailed]-notes.md`, a derived narration compilation.
The detailed version joins intro, walkthrough, and optional details; missing walkthroughs fail validation.
The PPTX contains the source visual rendered at 2400 pixels wide and embedded narration for every slide.
Original SVG/Markdown files remain individually editable. PowerPoint visual shapes are rendered images, not native editable diagram objects.
Reference metadata is kept in a separate part of each slide's PowerPoint notes, not counted as narration.
The build manifest records source hashes, tool versions, warnings, and note/count round-trip verification.
No source text or visual is regenerated by a language model during the build.

## Limits

SVG rendering and ordered narration are supported in v0.2; PlantUML, Mermaid, and PDF export are not implemented.
Self-contained PNG/JPEG data inside SVG is permitted but flagged as raster-backed.
External SVG resources and active content are rejected; this validation is not a complete hostile-file sandbox.
PPTX ZIP metadata is normalized. Repeat builds were byte-identical in the tested environment.
Cross-platform output may differ with Cairo, fonts, transitive dependencies, or library versions.
The tested host resolves Arial to Arimo and includes DejaVu Sans Mono; font files are not distributed.
Semantic review, human acceptance, and native Codex invocation remain separate verification tasks.

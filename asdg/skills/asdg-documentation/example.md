# Speaking-duration feedback: a Purpose assessment

This illustrative example separates a desired outcome from available evidence.
It describes no real project or completed test.

## Intended

The proposed outcome is to help a speaker notice when an answer is becoming too long.
Use during practice, live interviews or both remains a stakeholder decision.

## Actual

Suppose a code review finds a timer and color changes. That establishes source implementation;
browser behavior and improved answer quality remain untested.
Link the review and its baseline date rather than imply user benefit.

## Planned

A candidate next step is an observation session to learn whether the signal helps.
It becomes selected work only when its owner, scope and decision are recorded in the existing plan.

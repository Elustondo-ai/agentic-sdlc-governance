# Source and portable adaptations

This pilot was assembled on 20 October 2026 from the user-selected Google Drive working source:
[agentic-sdlc-governance](https://drive.google.com/drive/folders/1CzNrE_O6Vb39BK5d4EXtA3Uj2kSAYoqL).
It is a captured working-tree snapshot, not a claimed Git commit or release of that repository.
The old October 17 local clone and the newer sibling `asdg` repository were not substituted as source.
The attached earlier SDLC2 essays remain background; they do not override the current catalogue or user decisions.

`metadata/source-manifest.json` records source file IDs, paths, modification times and SHA-256 hashes.
`metadata/MANIFEST.json` records the current candidate; `metadata/deliveries/0.2.0-pilot.1.json` retains original delivery hashes.
These records establish provenance, not signatures or approval.
The [Apache 2.0 license](../LICENSE) is retained from the source.
Historical provider document-review events are preserved as history, not client evidence.
New documentation changes receive separate hashes and no inferred human approval.

## Adaptations

- Added project-local entry points and a repeatable, preflighted embedded initializer.
- Removed the machine installation and external-source baseline command from this pilot interface.
- Corrected catalogue/reference paths for the already-renamed stage 04 and 05 folders; numbering and responsibilities are unchanged.
- Moved the controlling lifecycle baseline into this distribution and repaired internal references.
- Generated native skills and thirteen role adapters from bundled templates, with explicit focus selection.
- Removed the obsolete adapter sandbox setting; current Codex inherits parent permissions. Read-only role instructions remain.
- Resolved hooks at runtime within the client; no developer home, sibling checkout or private environment is required.
- Protected the embedded methodology from application sprint scope.
- Centralized public child-activity records under root `logs/asdg/`, ignored by Git.
- Moved durable client document-review records to `.asdg/document-reviews.json`, outside disposable logs.
- Added explicit initial project-status selection; repeat initialization never changes an existing declaration.
- Retained deterministic status, evidence rules, sprint transitions, scope checks and optional SDK advice.
- Extracted the SDK environment helper from baseline capture without changing its filtering policy.

## Deliberate exclusions and pending work

Presentation/video production, the ASDG component-development scaffolder, developer setup, provider assessments,
old verification reports, `_NEW` alternatives and historical external baseline execution are excluded.
Legacy installation migration, arbitrary config merging and automated upgrades are not implemented in this pilot.
Existing conflicting configuration is preserved and reported before planned writes.
Native Mac trust/interception, live SDK advice, persisted-focus behavior and complete child-log callbacks
must be verified in the target runtime. Configuration and local tests do not establish those outcomes.
The [root-layout refactor](root-layout.md) is the first local revision; [review changes](review-loop.md) before promotion.

## Procedure

1. Identify the exact revision, environment, observation time and authorized review scope; separate staging from production.
2. Compare expected behavior and acceptance criteria with observed runtime and user feedback; mark missing evidence unknown.
3. Assess configuration, dependencies, rollout/rollback and operational risks without deploying or changing settings.
4. Document environment topology and acceptance evidence using the shared documentation skill; label documented versus observed claims.
5. Return environment findings, acceptance gaps and human decisions; request coordinator routing for implementation or release actions.
